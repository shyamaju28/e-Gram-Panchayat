# 🚀 e-Gram Panchayat - Quick Start

## ⚡ सिर्फ 3 Steps में शुरू करो!

### Step 1: Dependencies Install करो
```bash
npm install
```

### Step 2: Development Server चलाओ
```bash
npm run dev
```

### Step 3: Browser में खोलो
```
http://localhost:3000
```

---

## 🎯 Test करने के लिए

### Home Page
- http://localhost:3000

### Register करो
- http://localhost:3000/register
- कोई भी नाम, email, password डालो

### Login करो
- http://localhost:3000/login
- Same email और password से login करो

### Dashboard देखो
- http://localhost:3000/dashboard
- सभी features explore करो

### Complaints दर्ज करो
- http://localhost:3000/complaints
- शिकायत दर्ज करें (File Complaint)

### Certificates के लिए आवेदन करो
- http://localhost:3000/certificates
- आवेदन करें (Apply)

### Admin Dashboard
- http://localhost:3000/admin/dashboard
- सभी शिकायतें देखो
- Approve/Reject करो
